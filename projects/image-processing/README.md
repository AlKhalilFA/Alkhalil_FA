# مشروع معالجة الصور

ضع جميع ملفات مشروع معالجة الصور داخل هذا المجلد فقط، حتى يبقى مستقلًا عن مشروع التشفير.

## البنية المقترحة

```text
image-processing/
├── app.py                 # نقطة تشغيل المشروع إن كان تطبيق Flask
├── requirements.txt       # مكتبات معالجة الصور الخاصة بهذا المشروع
├── templates/             # قوالب HTML إن وجدت
├── static/                # CSS وJavaScript والصور الثابتة
├── src/                   # منطق معالجة الصور
├── tests/                 # الاختبارات
└── README.md
```

## قواعد مهمة

- لا تعدّل ملفات `projects/crypto/` من داخل هذا المشروع.
- ضع مكتبات مثل Pillow أو OpenCV في `requirements.txt` الخاص بهذا المجلد.
- شغّل أوامر المشروع من هذا المجلد أو استخدم مساراته صراحة.
- استخدم منفذًا مختلفًا عن مشروع التشفير إذا كان التطبيقان يعملان في الوقت نفسه، مثل `5002`.
